# AGENTS

This repository is a product catalogue MVP built with React and Node.js.

## Goals

- Keep a clean separation between frontend and backend.
- Use the Fake Store API only from the backend.
- Support local development without any paid account or secret configuration.
- Write tests covering the critical path.

## Workflow guidance

- Prefer small, readable modules with an explicit API boundary.
- Keep configuration in environment variables and document the example setup.
- Validate the critical path before finishing.
- Make assumptions explicit in the README and decision notes when the challenge leaves gaps.
